# RunNSee — Lot Glossaire V5 strict

## 1. Objectif

Créer ou finaliser une page Glossaire dédiée, stable et utile.

Le glossaire doit aider l'utilisateur à comprendre les indicateurs sans polluer les pages principales.

## 2. Route

```text
/glossaire
```

## 3. Structure attendue

```text
Header Glossaire
Recherche
Catégories
Cartes termes
Définition courte
Exemple / lecture
Alias techniques
```

| Terme technique | Terme visible |

## 5. Interdits

- Ne pas réintroduire une modale globale.
- Ne pas casser les ancres.
- Ne pas dupliquer les définitions partout.
- Ne pas supprimer les alias techniques.
- Ne pas utiliser les termes techniques comme libellés principaux.
